# 🤖 MAYA AI

### Futuristic Voice-Powered AI Assistant

**MAYA AI** is a Python-based voice assistant designed to interact with your computer through natural voice commands. It combines real-time AI conversation, web information, automation, application control, file operations, messaging, and Windows system controls into one assistant.

> **Talk to your computer. Let MAYA handle the task.**

---

## ✨ Features

### 🧠 AI Conversation

* Natural voice conversations
* Real-time AI responses
* Ask questions and get information
* General knowledge and topic research
* Context-aware conversations
* Voice-based interaction

### 🌐 Information & Web Search

* Search the web using voice commands
* Find information about different topics
* Open websites
* Search Google
* Get useful information without manually typing

### 💻 PC Control

MAYA can perform supported computer-control actions through voice commands, including:

* Open applications
* Close applications
* Switch between windows
* Minimize and maximize windows
* Show desktop
* Lock the computer
* Restart the computer
* Shut down the computer
* Control system volume
* Mute/unmute audio
* Adjust brightness where supported
* Perform keyboard and mouse actions

### 📁 File & Folder Operations

* Open files
* Open folders
* Search for files
* Work with supported file operations
* Navigate through the computer using voice commands

### 🌐 Application & Browser Control

* Open websites
* Control supported browser actions
* Search the web
* Navigate between supported browser functions
* Launch applications through voice commands

### 💬 Messaging & Communication

MAYA can assist with supported messaging actions, including:

* Send WhatsApp messages
* Send Messenger messages
* Send Snapchat messages

Messaging actions depend on the installed applications, logged-in accounts, permissions, and available interfaces.

### ⚙️ System Automation

MAYA is designed to automate supported computer tasks through voice commands instead of requiring manual interaction.

Examples include:

* "Open Chrome"
* "Search Google for Python"
* "Open my folder"
* "Turn the volume up"
* "Mute the computer"
* "Lock my PC"
* "Restart the computer"
* "Send a message"
* "Open this website"

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/MAYA-AI.git
```

### 2. Open the project

```bash
cd MAYA-AI
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure environment variables

Create a `.env` file and add the required API credentials and configuration.

**Never upload your `.env` file or API keys to GitHub.**

### 7. Start MAYA

```bash
python maya_ui.py
```

## 🔐 Security

MAYA can interact with your computer, so it should only be run in an environment where you understand and trust the commands being executed.

Never expose:

* API keys
* Access tokens
* Passwords
* Private credentials
* `.env` files
* Personal account information

Use `.gitignore` to prevent sensitive files from being committed.
